Features

Everything an operator needs.
Nothing they don't.

From slot-locking to subscription billing — WashFlow covers the full operational stack.

🏗️
Multi-Tenant Architecture
Full data isolation per tenant enforced at the ORM layer via Prisma Client Extensions. No cross-tenant leakage, guaranteed.
Prisma Extensions · Row isolation
🔒
RBAC with 47 Permissions
Granular role-based access control across 14 modules. Custom roles per tenant, permission gates in both UI and API.
JWT · Passport · Guards
📅
Conflict-Free Scheduling
Row-level locking inside Serializable transactions. Concurrent bookings guaranteed to never double-book a bay.
SELECT FOR UPDATE · Serializable tx
👥
Workforce Capacity Engine
Effective capacity = min(free bays, available workers on shift). Auto-assigns the best employee at booking time.
EmployeeProfile · Auto-assign
⚡
Real-Time Operations
Socket.IO broadcasts every order event to tenant rooms. Live dashboard reflects status changes across all devices instantly.
Socket.IO · Domain Events
🌐
Public Booking Widget
Embeddable standalone booking widget. Tenant resolved by header UUID. Rate-limited, idempotent, fully public API.
Widget · Slug routing
💳
Paddle Subscription Billing
4-tier plans with per-resource add-ons. Webhook-driven lifecycle, HMAC verification, Redis idempotency, downgrade guard.
Paddle.js · HMAC · Add-ons
📊
Analytics & CSV Export
KPI cards, branch comparisons, employee performance, cancellation anomaly alerts, and one-click CSV export of orders & clients.
Recharts · Prometheus · Grafana
🗑️
Unified Soft Delete
9 models with soft-delete, auto-filtered reads, restore endpoints, partial unique indexes, and 30-day hard-delete cron.
Auto-filter · Restore · Cron

◆ Rows locked with SELECT FOR UPDATE — zero double-booking
◆ Workforce cap applied — slot hidden when all workers are busy
◆ URL params ?branchId&date&time pre-fill the create wizard

How it works

From setup to
first booking in minutes.

01

Register your car wash

One form creates your tenant, admin account, and a 30-day trial subscription with full access — no credit card required.

02

Configure branches & bays

Add branches, define work posts, set working hours and booking buffers per location. Each branch gets its own scheduling engine.

03

Set up your team

Invite staff, assign roles with granular permissions, and create workforce profiles with shift hours for capacity tracking.

04

Go live — online & walk-in

Embed the public booking widget on your website. Accept walk-ins from the internal CRM. Everything syncs in real time.
